Important note: This aviation demo is implemented to work with different sizes
of the aviation instruments.

If you want to change the size of the instrument set, just copy all *.png files
from one of the sub-directories (e.g. \100x100 or \320x320) into the \Res
directory and replace all of the existing *.png files.

For this purpose, you can use the provided *.bat files.

After reloading the project within Embedded Wizard, the bounds and positions
of all instruments are rearranged automatically. Don't forget to set the
ScreenSize within your Profile to the size of your panel.
